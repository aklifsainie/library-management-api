## 1. Book Endpoints

| Method   | Endpoint          | Purpose                 |
| -------- | ----------------- | ----------------------- |
| `POST`   | `/api/v1/books`      | Add a book              |
| `GET`    | `/api/v1/books`      | List books              |
| `GET`    | `/api/v1/books/{id}` | Get a book’s details    |
| `PUT`    | `/api/v1/books/{id}` | Update book information |
| `DELETE` | `/api/v1/books/{id}` | Delete a book           |
